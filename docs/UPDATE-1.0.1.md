# PicHarbor 1.0.1：登录界面与原生动效

版本 1.0.1（10001），沿用正式包名和签名，可覆盖安装 1.0.0，保留本地设置、凭据和记录。

## 本轮变化

- Google 登录外壳改为原生 Compose / Material 3：关闭按钮、品牌引导、安全连接提示、加载状态、进度条、网络错误与重试；移除验证版“阻塞”等测试文案和旧系统按钮。
- 跟随应用浅深色、动态色与手动配色。键盘弹出或横屏时收起辅助区域，为 Google 页面留出空间。旋转保留页面历史和当前登录会话，结束登录仍清理会话。
- Google 网页保持自身样式和已验证的 EmbeddedSetup 认证流程，不修改 User-Agent、不添加凭据脚本桥、不注入 CSS；继续验证 HTTPS 证书、限制页面域名并保护登录截图。
- 页面切换增加短距离移动与淡入淡出，切换页面保留滚动位置；底部导航栏与忙碌进度条平滑显隐。
- 照片多选增加缩进、圆角和选中标记动画，批量操作栏滑入/滑出；操作栏可横向滚动以适应大字体。
- 备份状态图标/标题渐变，设置组高度变化与文件进度平滑过渡。使用 Compose 原生动画机制，无自建循环动画计时器；系统动画缩放由 Compose 处理。

依据：[Compose 原生动画组件与修饰符](https://developer.android.com/develop/ui/compose/animation/composables-modifiers)。没有增加实验动画依赖，Material 3 继续固定 1.4.0。

## 验证范围

本轮只改变界面、页面状态及交付脚本，没有修改 gpmc 或认证请求参数。集中执行 Release 构建、静态检查、引擎基线、APK 内容与签名验证，不重复运行无关后端测试。

Release 构建和 lintRelease 通过（0 错误、25 警告、2 提示），原始 31 个引擎文件和 2 个扩展哈希一致。警告主要为现有 KTX/依赖/构建建议，另有小屏判断使用 Configuration 的建议，不隐藏报告。APK 内容、正式签名和 16 KiB 对齐检查通过，签名证书与 1.0.0 一致。

机器可读结果见 `release-1.0.1-checks.json`。没有连接 Android 真机，登录视觉、键盘/横屏表现、实际 Google 登录与动画流畅度仍待真机确认；没有执行照片删除。原始 1.0.0 验收范围保留在 RELEASE-VALIDATION.md。
