# 正式版架构与功能

Application 在主线程启动 Python 并首次导入 gpmc，保留原始 signal 注册；网络与哈希在工作线程执行。启动恢复完成前任务协调器不运行，避免遗留暂存清理与新传输竞争。

## 数据与账号

Room 是任务状态唯一依据，保存 media / backups / jobs / items / cleanups。媒体使用内容 URI，记录大小、修改时间和来源。备份与清理证据按账号隔离。账号切换取消旧调度并等待在途操作结束，暂停旧账号未完成任务、使清理证据失效，然后连接新账号。多个账号的凭据分别用独立 Keystore AES-GCM 密钥和账号 AAD 加密，禁止 Android 自动备份。移除账号仅删除其凭据和偏好，保留历史；切换失败保留原账号。gpmc 账号散列 SQLite 仅保存云端同步缓存和相册索引。

DataStore 保存备份范围、网络、画质、相册、调度和外观。默认相机、Wi-Fi、视频、2 并发、60 秒超时、3 次网络重试；首次选择范围后由用户确认开启自动备份。

## 媒体与界面

MediaStore 分卷扫描，排除待发布和回收站媒体。SAF 保留目录权限，可连接 SD 卡。部分授权只枚举可见内容，不推断全设备状态。手动选择文件保留授权。能通过文件描述符读取时直接流式传输，无法寻址才逐文件暂存，结束释放。

原生 Compose：照片日期时间线与筛选、长按多选、图片缩放与视频播放、备份进度和控制、任务历史、目录/相册/画质/网络/定时/后台设置、账号、外观和清理。跟随系统浅深色、Android 12+ 动态色、薰衣草/鼠尾草/暖杏。无演示账号、远程示例图片、手工凭据导入入口。

## 上传与恢复

逐文件 SHA-1/SHA-256、内容查重、原有上传和提交请求。同哈希分段互斥，避免一批相同文件并发上传。三种质量沿用原请求参数：原始画质 Pixel XL、节省空间 Pixel 2、计配额原画质 Pixel 8。没有用本地零配额推断服务端结果。

提交后先持久化内容证据，再归类相册。归类失败返回 album_pending，仅重试归类。同名跳过不生成内容证据。取消、认证失效、失败、未知分别保留。文件级恢复不包含字节级断点续传。上传前后检查元数据和内容哈希；变化后旧证据失效。

自动检查与手动批量备份前刷新云端状态，缺失或回收站项目使旧记录失效。离线缓存不作为清理依据。历史任务完整保留并可浏览；统计由数据库聚合，明细单独查询并分批展示。图库仅加载最近 10000 条任务状态辅助标记，全部备份凭证独立加载，因此旧任务不会造成成功统计截断或丢失备份凭证。

手动 Android 14+ 使用 UIDT，旧系统或无法登记时使用前台 Worker。自动使用 WorkManager、媒体变化去抖、约 15 分钟兜底，或每日所选时间附近执行。定时和周期互斥，时区/系统时间变化重新登记。重启仅登记调度。系统停止后回队重试，用户暂停则保持暂停。厂商限制、系统配额与低存储可能延后执行。

## 释放空间

重新计算本地 SHA-1/SHA-256，当前账号云端哈希匹配，最新云端状态明确非回收站、原始质量与状态字段存在、大小一致，再检查原件 URL。HEAD 不支持时 Range bytes=0-0，流式请求不读取整个响应。仅接受 Google HTTPS 域名，重定向逐跳校验，不保存临时 URL。

缺字段（包括整个回收站字段缺失）保持未知，拒绝清理。经过真实测试文件的正常、移入回收站、恢复三态对照后，允许在本次完整云端快照内将明确存在的空回收站标记解释为未删除；字段缺失或格式不明仍不能据此推断。该语义扩展不修改原始 gpmc 基线。

Room 版本 2 使用非破坏性迁移增加 CleanupScan 与 CleanupScanItem，持久保存检查会话、候选项目及逐项完成标记。独立前台 CleanupWorker 执行检查，页面只订阅数据库状态，离开页面不取消。默认同时检查 2 项，按账号可设 1～3 项；每批结束后才刷新快照，避免刷新使在途核验失效。进程中断后从持久记录恢复，并重新确认此前合格项目；主动取消及切换账号会废止清理资格。通知显示检查数量与完成结果，点击返回对应账号的检查页。

核验有效期 5 分钟，删除前再次核对内容。系统确认期间仍有系统级文件变化窗口，需及时操作。MediaStore 使用系统删除授权（Android 10 逐项兼容），SAF 仅处理写权限内容；最多 100 项一批。实际查询文件不再存在才计入释放量，权限丢失不等于删除。取消、部分成功和失败保留记录。无云端删除或上传后自动删除调用。
