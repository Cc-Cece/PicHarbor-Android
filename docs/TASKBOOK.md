# gmgc-apk 最小实例任务书

工作目录：`C:\Users\Kanbara\Code\vscode\gmgc-apk`。

## 必须同时验证的目标

1. 普通未 Root 手机自助登录：用户只进行 Google 登录、两步验证及必要确认，无电脑、无手工 Cookie 或 Token。
2. 使用现有 gpmc 原画质上传新的 JPEG、HEIC、MP4，实际不计 Google 相册配额。

## 实现约束

- 独立 Android 工程，Kotlin + Compose + Chaquopy，Android 10+ arm64。
- 完整复制 gpmc、blackboxprotobuf，保留桌面桥接参考、来源、许可证、全部文件哈希。
- 首次移植不改引擎源代码，不 monkey patch；后续业务逻辑在本项目 gpmc 中维护。
- 外层仅负责 Android 登录接入、文件准备、凭据保护、UI、报告；不重新实现协议。
- WebView 登录被拒绝、设备验证不支持或令牌加密无法处理时，明确判为阻塞，不伪造成功。
- 若引擎必须改动才能运行，先记录兼容问题与最小修改建议，不混入首次复制。

## 最小功能

登录、账号状态、媒体选择、前台单线程上传、进度、原文件回下载哈希比对、人工官方详情记录、凭据复用与实际续期验证、退出和脱敏报告。

不包含自动备份、后台持续上传、多账号、相册分类或全库浏览。诊断注入只用于隔离问题，不作为自助登录验收。

## 验收

逐字节源码校验；独立构建；真机首次登录和重启复用；实际令牌过期续期；新样本原画质和下载原文件哈希一致；官方条目明确不占空间并在处理后复查；登录取消、断网、失效凭据和不支持响应无虚假成功。

上传成功、本地缓存零配额、云端重复条目均不能证明免配额。缺少证据记为未知。已上传云端文件不自动删除。
