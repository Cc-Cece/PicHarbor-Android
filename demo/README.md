# 云备份 · Android 前端交互原型

这是用于讨论正式 Android 应用前端的独立原型，采用 Material 3 Expressive 的布局、配色与交互风格。没有接入 Google 或 APK 后端，不会请求登录凭据、上传或删除真实文件。

## 打开

直接双击 `index.html` 即可浏览，所有示例照片均保存在 `assets/`。

推荐通过本地 HTTP 预览：

```powershell
cd C:\Users\Kanbara\Code\vscode\gmgc-apk\demo
node serve.mjs
```

浏览器打开 **http://127.0.0.1:4173**。无需安装依赖或构建。服务器只绑定本机回环地址；它只是静态文件服务，不是业务后端。

手机尺寸显示为全屏应用；电脑显示手机画幅与演示控制面板。手机右下角的星形按钮可打开演示控制。

## 可以体验

- 照片时间线、状态筛选、照片/视频与日期筛选、详情查看、日期分组选择及长按多选。
- 手动备份、模拟进度、暂停/继续、完成与任务记录。
- 首次登录演示、账号状态、切换/退出账号。
- 备份文件夹、SD 卡授权演示、相册归类、自定义/已有相册。
- 自动备份开关、定时、仅充电、网络及移动流量选项。
- 释放空间：查看待核验项目 → 模拟核验 → 清理说明 → 模拟系统确认 → 结果。
- 浅色/深色、薰衣草/鼠尾草/暖杏主题。
- 待备份、全部完成、等待 Wi-Fi、失败重试、未登录等预设场景。

所有任务状态只保存在当前页面内存，刷新即可还原；仅主题偏好保存在浏览器本地。照片是静态示例，视频使用示例封面和时长，未包含真实视频播放。自动/定时/后台选项仅展示交互，不会在关闭网页后执行。

示例账号 `lin.demo@example.com` 不对应真实 Google 登录。页面中的容量、日期、云端核验与清理结果均为演示值。正式应用仍使用 Android 官方 Material 组件；本原型用原生 HTML/CSS/JavaScript 模拟，无前端框架或远程字体依赖。
